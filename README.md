# 💅 Ежедневник мастера маникюра: Telegram Mini App

Telegram Mini App + бот-ассистент для мастера маникюра и педикюра.  
Работает 24/7 в бессерверном облаке **Cloudflare Workers** с базой данных **Turso (libSQL/SQLite)**.

---

## 🌸 Возможности

- **📅 Полоса недели со свайпом (Пн–Вс)**: индикация записей точками и значок 📝 при наличии заметок.
- **✨ Свободные окна дня**: автоматический расчёт и визуальные бейджи свободных окон с учётом графика работы мастера и существующих записей; клик по окну сразу открывает форму записи на это время.
- **💅 Запись клиентов**:
  - Быстрый выбор времени начала приёма.
  - Опциональная длительность (по умолчанию: маникюр 2 ч, педикюр 1.5 ч, комплекс 3.5 ч) с возможностью изменить в один клик.
  - Услуги: маникюр / педикюр / комплекс.
  - Раздельные покрытия: с покрытием (гель) / без покрытия.
  - Автоматическая проверка интервальных пересечений $[start, end)$ с понятным предупреждением.
  - Автоподстановка клиентов из базы при вводе имени.
- **👥 База клиентов (отдельный раздел)**:
  - Карточки клиентов с поиском.
  - Номер телефона с быстрым звонком и кликабельная ссылка на профиль Telegram.
  - Индивидуальные заметки мастера (аллергия на материалы, предпочтения, особенности).
  - 🎂 **День рождения клиентки**: указание числа и месяца, праздничный бейдж и **автоматическое напоминание от бота в 10:00 утра** (по Кишиневу) в день рождения клиентки со всеми её контактами.
  - История визитов и кнопка быстрой записи.
- **📝 Заметки на каждый день**: сохраняются в приложении и мгновенно дублируются сообщением в Telegram.
- **🔔 Сообщения о записях и заметках**: бот присылает уведомления при создании и автоматически удаляет их из чата через сутки, чтобы не засорять переписку мастера.
- **🌙 Вечерние напоминания**: бот каждый вечер (по умолчанию в 22:00) присылает расписание на завтра со списком клиентов, контактами (телефон / Telegram) и заметкой.
- **⚙️ Настройки графика**: выбор рабочих дней (Пн–Вс), начала и окончания рабочего дня, времени вечернего уведомления.
- **🔒 Надёжность сессии и защита от гонок**:
  - При истечении срока `initData` (24 часа) отображается понятный экран с кнопкой перезагрузки без ложных ошибок 403.
  - Защита от race conditions на фронтенде при быстром переключении дней (`AbortController` + sequential `requestId`).
- **📊 Экспорт в Excel / CSV**: безопасная выгрузка всех записей в таблицу CSV (с сохранением телефонных номеров с `+` и защитой от CSV-инъекций) прямо в чат Telegram.
- **🎨 Дизайн**: мобильный интерфейс, нежная пудрово-розовая палитра, полная поддержка светлой и тёмной тем Telegram.

## 🛠 Стек технологий

- **Бэкенд**: Cloudflare Workers, TypeScript, Hono.
- **База данных**: Turso (libSQL / SQLite) через `@libsql/client/web` (атомарные транзакции `batch`).
- **Фронтенд**: Чистый JavaScript (Vanilla), HTML5, CSS3 без сборщиков и сторонних фреймворков.
- **Telegram WebApp**: BackButton, MainButton, HapticFeedback, showConfirm.
- **Фоновые задачи**: Cloudflare Cron Triggers (`* * * * *`): проверка вечерних уведомлений и автоудаление сервисных сообщений из чата.
- **Тесты**: Vitest (`npm test`), 67 тестов: проверка HMAC-SHA256 подписи Telegram `initData`, валидация записей и длительности, расчёт свободных окон, логика вечерних напоминаний, экранирование CSV.

## 🚀 Быстрый запуск и деплой

### 1. Установка зависимостей
```bash
npm install
```

### 2. Секреты Cloudflare
Задаются через команду `wrangler secret put`:
```bash
npx wrangler secret put BOT_TOKEN        # Токен бота от @BotFather
npx wrangler secret put ALLOWED_IDS      # Telegram ID мастеров через запятую
npx wrangler secret put WEBHOOK_SECRET   # Секретная строка для защиты вебхука
npx wrangler secret put TURSO_AUTH_TOKEN # Токен доступа к базе Turso
```

Переменная `TURSO_DATABASE_URL` указывается в `wrangler.toml` или в `.dev.vars` для локальной разработки.

### 3. Автоматическое применение миграций к Turso
В проект встроен скрипт накатывания недостающих миграций:
```bash
npm run migrate
```
Скрипт проверяет таблицу `schema_migrations` в Turso и выполняет только не применённые файлы:
- `0001_init.sql` — начальная структура записей
- `0002_notify_22.sql` — перевод уведомлений на 22:00
- `0003_schema_hardening.sql` — нормализация схемы и создание `schema_migrations`
- `0004_notify_options.sql` — настройка `notify_new_appt` и таблица `scheduled_deletes`
- `0005_optional_end_time.sql` — опциональный `end_time`
- `0006_clients_and_schedule.sql` — таблица клиентов `clients` и поля графика работы мастера в `users`
- `0007_client_birthdays.sql` — колонка `birthday` (число и месяц) в `clients` и дата утренней отправки в `users`

### 4. Тесты и проверка типов
```bash
npm test
npm run typecheck
```

### 5. Деплой приложения
```bash
npm run deploy
```

### 6. Установка Webhook Telegram
```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
  -d "url=https://<WORKER_URL>/webhook" \
  -d "secret_token=<WEBHOOK_SECRET>"
```

## 💬 Команды бота

- `/start` / `/menu` — приветствие, обучение и кнопка входа в Mini App.
- `/today` — расписание на сегодня.
- `/tomorrow` — расписание на завтра.
- `/notify` — принудительно сформировать и прислать вечернее расписание.
- `/id` — узнать свой числовой Telegram ID (строгое совпадение команды).
