# Команды бота и доступ

[← NailBook](../README.md)

## Для мастера

| Команда | Назначение |
| --- | --- |
| `/start`, `/menu` | Приветствие и кнопка входа в Mini App. |
| `/today` | Расписание на сегодня. |
| `/tomorrow` | Расписание на завтра. |
| `/notify` | Сформировать вечернее расписание вручную. |
| `/id` | Узнать свой Telegram ID, если включён `ENABLE_ID_COMMAND`. |

Вечернее расписание приходит по времени и часовому поясу мастера; стандартное время — 22:00. Напоминания о днях рождения отправляются после 10:00 в часовом поясе мастера. Фоновые проверки выполняются Cron каждую минуту.

Новые записи и изменённые непустые заметки могут дублироваться в Telegram. Такие сервисные сообщения ставятся на удаление через сутки; записи и заметки остаются в базе. Сообщения о новых записях можно отключить отдельно в настройках.

## Для администратора

Администраторы задаются в `ADMIN_ID`: один ID или несколько через запятую. Им доступны следующие команды:

| Команда | Назначение |
| --- | --- |
| `/admin` | Список команд. |
| `/users` | Пользователи, доступ, количество записей и клиентов. |
| `/user ID` | Данные о пользователе, его доступе, объёмах данных и настройках. |
| `/stats` | Сводка по всей базе. |
| `/health` | База, миграции, бот и состояние webhook. |
| `/export` | Список пользователей и количество их записей. |
| `/records` | Все записи всех мастеров в CSV с ID владельца. |
| `/records ID` | Записи одного мастера в CSV. |
| `/export ID` | CSV и JSON-копия данных одного мастера. |
| `/backupall` | JSON-копии пользователей из базы. |
| `/send ID текст` | Личное сообщение от администратора. |
| `/broadcast текст` | Сообщение пользователям с доступом и итог доставки. |
| `/adduser ID` | Выдать доступ и отправить пользователю уведомление. |
| `/ban ID` | Закрыть доступ с сохранением данных. Администратора заблокировать нельзя. |
| `/unban ID` | Снять блокировку. |

Для `/send` и `/broadcast` текст ограничен 3500 символами. Если пользователь ещё не начал диалог с ботом, доставка личного сообщения может быть недоступна.

## Права

Обычный доступ — это `ALLOWED_IDS` и пользователи, добавленные через `/adduser`, за исключением заблокированных через `/ban`. Если прочитать состояние блокировок не удалось, обычный доступ закрывается. Права администратора проверяются отдельно; включение в `ALLOWED_IDS` ему не требуется.

Кнопка администратора в шапке Mini App открывает список мастеров. После выбора появляется плашка владельца; администратор может создавать, менять, переносить и удалять его записи. В этом режиме изменение клиентов, заметок, финансов, настроек, прайса и импорт закрыты. Выход из несохранённой формы требует подтверждения.

Наблюдатели из `VIEWER_IDS` могут использовать `/admin` и `/records` для просмотра записей. Изменение данных, выдача доступа и рассылки им недоступны.
