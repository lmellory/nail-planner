## 1. Краткое ТЗ

**Кто пользуется:** мастер маникюра/педикюра (1, максимум 2 человека). Бот закрытый, остальным не отвечает.

**Что это:** Telegram Mini App «ежедневник» + бот с уведомлениями. Работает 24/7, срока завершения нет.

**Записи:**
- имя клиента, «кто это, что за человек»
- услуга: маникюр / педикюр / оба
- у каждой услуги: с покрытием или без
- начало и конец (конец строго позже начала), комментарий
- добавлять, редактировать, переносить, удалять (удаление с подтверждением)
- пересечение по времени: предупреждение, но не запрет

**Календарь:**
- неделя Пн–Вс, нажимаешь на день и видишь все записи
- под числами точки по количеству записей и значок 📝, если есть заметка
- листание недель свайпом, переход к любой дате
- диапазон: с 1 января текущего года до сегодня + 3 года (записи на май вносятся позже, поэтому прошлое и будущее доступны)
- заметка к каждому дню, необязательная

**Уведомление:** каждый день в 23:00 (время и вкл/выкл в настройках) бот присылает расписание на завтра: кто, во сколько, что делаем, комментарии, заметка дня и кнопка открытия приложения. Защита от дублей, досылка пропущенного до 03:00.

**Безопасность:** проверка подписи initData (HMAC-SHA256), доступ только для ID из ALLOWED_IDS, user_id только из подписи, все SQL-запросы с фильтром по user_id.

**Дополнительно:** поиск клиента, экспорт CSV/JSON, бэкап, команды бота `/start /menu /today /tomorrow /id`.

**Дизайн:** по-русски, мобильный, светлая и тёмная темы Telegram, нежная пудрово-розовая палитра.

## 2. Стек (финальный)

- Cloudflare Workers + TypeScript + Hono (API и бот)
- Бот через webhook (без long polling), проверка заголовка `X-Telegram-Bot-Api-Secret-Token`
- База: Cloudflare D1 (SQLite), миграции в `migrations/`
- Фронтенд: чистые HTML/CSS/JS без сборки, папка `webapp/` (Workers Static Assets)
- Уведомления: Cron Trigger каждую минуту
- Деплой: GitHub → Cloudflare Workers Builds, либо `wrangler deploy`
